# PsychoAnalitics

PsychoAnalitics — прототип веб-чата на базе GigaChat. Пользователь пишет сообщение и может включить камеру, чтобы чат использовал оценку мимики как дополнительный контекст для ответа.

Прототип получил максимальный балл на кейс-чемпионате ВШЭ. Данил Сивец самостоятельно разработал и развернул приложение, включая интеграцию GigaChat и модуля анализа кадров.

## Сценарий работы

1. Пользователь открывает чат и отправляет сообщение. Flask-SocketIO передаёт сообщения между браузером и сервером.
2. При включённой камере браузер отправляет кадр на Flask-сервер. OpenCV сохраняет временное изображение, а скрипт на Node.js анализирует его с помощью face-api.js. Модель оценивает выражение лица, возраст и пол. В интерфейс возвращаются оценки выражения лица и пола.
3. Сервер отправляет текст сообщения и, при наличии, оценку выражения лица в запросе к GigaChat. Ответ возвращается в чат.

## Код проекта

| Компонент | За что отвечает |
| --- | --- |
| [`main.py`](main.py) | Flask-приложение, маршруты главной страницы и чата, события Socket.IO и обработка кадров. |
| [`static/script.js`](static/script.js) | Отправка сообщений, управление камерой и вывод результатов анализа. |
| [`analyze.py`](analyze.py), [`node_project/face_api.js`](node_project/face_api.js) | Вызов анализа из Python и работа с моделями на Node.js. |
| [`gigachat.py`](gigachat.py) | Получение токена GigaChat и генерация ответов. |

## Что нужно для локального запуска

Установите зависимости Python из [`requirements.txt`](requirements.txt) и зависимости Node.js из lock-файла командой `npm ci --prefix node_project`. Скрипт анализа загружает модели из каталога [`model/`](model/).

Запустите `python main.py` из корня репозитория и откройте `http://127.0.0.1:5000/chat`. Для проверки диалога нужно заменить учётные данные на собственные и настроить проверку TLS для запросов к GigaChat.
